# Enterprise SSO – Identity API

The ASP.NET Core (.NET 10) identity provider. Architecture, configuration, API reference, migrations, testing and the
production checklist are documented in the [repository README](../README.md).

- Relying-party integration: [docs/THIRD_PARTY_APP_INTEGRATION.md](docs/THIRD_PARTY_APP_INTEGRATION.md)
- Run: `dotnet run --project UserService.Api` (see *Local development* in the root README for the required variables)
- Test: `dotnet test`
