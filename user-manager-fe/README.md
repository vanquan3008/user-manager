# Enterprise SSO – Admin console

The Angular 19 + Tailwind admin console, which also serves the hosted sign-in and consent pages. See the
[repository README](../README.md) for features, configuration (`NG_APP_*` variables) and deployment.

```bash
cp .env.example .env
npm ci
npm start        # http://localhost:4200
npm run build    # production build in dist/
```
